# DELTA SCHOOL — Fusion V22 + V27

Cette archive conserve les fichiers et fonctionnalités de base de V22, notamment index.html, priority.js et les dépendances déclarées, et ajoute les fichiers exclusifs de V27 (identité élève, dossiers, migration ISII, guides). Les modules JavaScript partagés concernés par la synchronisation, la messagerie et l'API ont été repris de V27.

À vérifier avant production : exécuter les tests, comparer les changements de modules partagés, vérifier les droits serveur et examiner la migration SQL avant exécution sur Neon. Ne pas exécuter de migration sur la base de production sans sauvegarde.
